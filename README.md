# 🇺🇸 미국 시장 데일리 브리핑 → 텔레그램 자동 발송

매일 아침 **한국시간 07:15경**, 직전 미국 정규장 마감 브리핑(서사형 한국어)을 텔레그램으로 받는 자동화 패키지입니다.

동작 구조:

```
GitHub Actions (매 평일 UTC 22:15 = KST 화~토 07:15 자동 실행)
  → yfinance로 지수·금리·달러인덱스·유가·VIX·섹터ETF·개별종목 실측 데이터 수집
  → Claude API가 데이터 + 웹검색(급등락 사유)으로 서사형 브리핑 작성
  → 텔레그램 봇이 내 계정으로 발송
```

PC를 켜둘 필요가 없고, GitHub Actions는 공개 저장소 기준 무료입니다.
Claude API는 사용량 과금이며 이 작업 기준 하루 수십 원 수준입니다.
(API 키를 넣지 않으면 서사 없이 수치 중심 브리핑으로 자동 대체 발송됩니다.)

---

## 1단계 — 텔레그램 봇 만들기 (5분)

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력 → 봇 이름, 아이디(예: `my_market_brief_bot`) 지정
3. BotFather가 알려주는 **봇 토큰**(`123456789:AAF...` 형태)을 복사해 보관
   - ⚠️ 토큰은 비밀번호와 같습니다. 채팅이나 코드에 직접 붙여넣지 마세요.

## 2단계 — 내 chat_id 확인

1. 방금 만든 봇을 검색해 **아무 메시지나 하나 전송** (예: "안녕")
2. 브라우저 주소창에 아래를 입력(토큰 부분 교체):
   ```
   https://api.telegram.org/bot<봇토큰>/getUpdates
   ```
3. 응답 JSON에서 `"chat":{"id":123456789,...}` 의 **숫자**가 내 chat_id

## 3단계 — GitHub 저장소 만들기

1. github.com 가입/로그인 → **New repository**
2. 이름 예: `us-market-brief` → **Private** 권장 → Create
3. 이 패키지의 파일들을 저장소에 업로드
   - 웹 화면에서 "uploading an existing file"로 드래그&드롭 가능
   - ⚠️ `.github/workflows/daily_brief.yml`의 **폴더 구조가 그대로 유지**되어야 합니다
     (웹 업로드 시 폴더가 빠지기 쉬우니, "Add file → Create new file"에서
     파일명에 `.github/workflows/daily_brief.yml`을 입력하고 내용을 붙여넣는 방법이 확실합니다)

## 4단계 — 시크릿(비밀값) 등록

저장소에서 **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 값 | 필수 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | 1단계의 봇 토큰 | ✅ |
| `TELEGRAM_CHAT_ID` | 2단계의 chat_id | ✅ |
| `ANTHROPIC_API_KEY` | console.anthropic.com에서 발급한 API 키 | 선택(서사형 브리핑용) |

## 5단계 — 테스트

1. 저장소 상단 **Actions** 탭 → 워크플로우 활성화(Enable) 확인
2. **US Market Daily Brief** 선택 → **Run workflow** 버튼으로 수동 실행
3. 1~3분 내 텔레그램으로 브리핑이 도착하면 성공 🎉
4. 이후로는 매 평일 미국장 마감 후, **화~토 아침 07:15~07:40(KST)** 사이에 자동 도착합니다

## 자주 묻는 것

**Q. 월요일 아침에는 왜 안 오나요?**
미국장은 토·일 휴장이라 일·월요일 아침에는 새로 마감된 세션이 없습니다.
(토요일 아침에 금요일장 브리핑이 도착합니다.)

**Q. 주말에 테스트하고 싶은데 "휴장 안내"만 와요.**
Actions → **US Market Daily Brief** → **Run workflow** 를 누르면 나오는
**"휴장(주말·공휴일)이어도 직전 마감 세션 브리핑을 강제 발송"** 체크박스를 켜세요.
직전 거래일 기준으로 실제 브리핑을 만들어 보냅니다(스케줄 실행에는 영향 없음).

**Q. 미국 공휴일(노동절, 추수감사절 등)에는?**
스크립트가 휴장을 자동 감지해 "휴장 안내" 메시지를 보냅니다.
아예 조용히 넘어가길 원하면 워크플로우의 `SKIP_ON_HOLIDAY: "1"` 주석을 해제하세요.

**Q. 도착 시각을 바꾸고 싶어요.**
`daily_brief.yml`의 cron을 수정하세요. **UTC 기준**이며 KST = UTC+9입니다.
예) KST 07:45 도착 목표 → `45 22 * * 1-5`
⚠️ 겨울(EST)에는 미국장 마감이 UTC 21:00입니다. UTC 21:30보다 이르게 당기면 yfinance 일봉이
아직 갱신되지 않아 정상 거래일에도 "휴장" 안내가 갈 수 있으니 여유를 두세요.

**Q. 급등락 스캔 종목을 바꾸고 싶어요.**
`main.py` 상단의 `MOVER_WATCHLIST`, `NASDAQ_MEGACAP_CANDIDATES` 리스트를 수정하면 됩니다.
급등 Top10은 이 워치리스트(대형주) 기준이라 초소형주 포함 시장 전체 순위와는 다릅니다.

**Q. 브리핑 말투/구성을 바꾸고 싶어요.**
`main.py`의 `SYSTEM_PROMPT`를 수정하세요. 여기가 브리핑의 "성격"을 결정합니다.

**Q. 비용은?**
- GitHub Actions: 프라이빗 저장소도 월 2,000분 무료(이 작업은 하루 2~3분 사용)
- Claude API: 하루 1회 호출 + 웹검색 몇 건 → 월 1~2달러 내외(모델·검색량에 따라 변동)
- 텔레그램 봇: 무료

## 주의

- 본 브리핑은 정보 제공 목적이며 투자 권유가 아닙니다.
- yfinance(야후 데이터)는 무료 소스 특성상 드물게 지연/누락이 있을 수 있습니다.
  스크립트는 누락 항목을 N/A로 표기하고 나머지를 정상 발송합니다.
